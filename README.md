# Hold or Stop

## Short description

Stop the moving marker at the right moment.

## Description

Hold or Stop is a multilingual timing and precision game packaged as a lightweight browser extension. Players stop a moving marker inside a target area while the game tracks score, precision, streaks, and completed games.

## Purpose

The extension offers a quick skill-based challenge for practicing timing, attention, and hand-eye coordination without leaving the current browsing session.
